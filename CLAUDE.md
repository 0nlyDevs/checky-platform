## The project in one paragraph

**Checky** (named FANILO until 2 Nov 2026; the repos keep the old name) is a verification tool for newsrooms, Madagascar first and world-ready, made for the FANILO Hackathon (IFM + French Embassy press service, Antananarivo), where teams of 4 build an app for journalists around information resilience: verifying claims, misinformation, AI-generated content. The exact problem is presented by video on **Mon 2 Nov 2026, 08:00**. Hard deadline **Tue 3 Nov 20:00**, 3-minute pitch **Wed 4 Nov** at the IFM. Goal: a journalist follows a rumour from its first appearance to a signed verdict, and Checky sends the truth back down the same road (WhatsApp, Facebook, radio, SMS, a printed poster). Tagline « La torche des rédactions ». Product thinking lives in the Claude Doc « FANILO Hackathon — The brief, decoded, and how we win » (https://claude.ai/artifact/UxknwB4fr7EMXHFZxW7S2Y: tabs Winning idea, Functionality, Stack, Pitch); keep it in sync with the code.

## Checky: the product rules (2 Nov)

These rules are the product, the pitch and the jury answer. Every screen and route follows them.

- **Knowing is not publishing.** Checky states *facts* at once (a dated first appearance of a video, a registry diff against the original communiqué, an official figure, a fact-checker's published review, « une rédaction suit cette rumeur depuis… »). « Signer et publier » is a byline, needed only to send a verdict out under the newsroom's name. The public never sees « Lecture de Checky » (the AI reading), a percentage or a dossier.
- **Facts solid, readings dashed.** Computed from sources without a model = solid block. Written by a model = dashed outline labelled « Lecture de Checky ». A journalist's signature turns the verdict solid. Verdicts are icon + word, never colour alone.
- **The crew.** A check runs as a graph of agents named after verification jobs (`app/core/graph.py`, LangGraph semantics on our gateway: stages in order, nodes of a stage in parallel, per-node timeout, failures reported never fatal, `llm` nodes skipped as `no_ai` when `settings.ai_enabled` is false, one bounded loop): Lecteur (one model call) → Provenance, Registre, Chiffres, Fact-checkers, Web, Archives, Fiabilité, Ton (code) → Synthèse (one call) → Contradicteur (one call, one loop back) → confidence in code → the journalist. Three model calls per check at most; the percentage is computed from evidence (`app/core/confidence.py`), never asked to the model.
- **One kind of account, no roles** (`app/core/access.py`): every member of a newsroom is one of its journalists and may do everything the newsroom can do (`AnyMember`; outsiders get 404). Invitations carry no role; any member removes a colleague or leaves, never the last one (409 `last_member`). Radio partners, contacts asked a question and citizens use token links and SMS, no account. « Signer et publier » is one signature; a signed and published dossier refuses a PATCH that changes the signed version until it is signed again (`items.update_item`, 409 `signature_required`).
- **Verified newsrooms** (`app/modules/verification.py`): « Tout le monde peut vérifier ; seules les rédactions vérifiées publient. » At creation (onboarding step 2, or later in Réglages → Vérification) a newsroom sends a request: outlet, kind (radio/tv/press/online), city, region, country, website or official Facebook page, full name, job title, phone (E.164 through `phonenumbers`), professional email, optional press card. The Checky team (`PLATFORM_ADMINS`: Better Auth user ids; an email entry only counts once the token says `emailVerified`) calls the number shown on the outlet's official page, then approves or refuses with a reason on `/checky` (`GET /platform/requests?status=`, `POST /platform/requests/{ws}/approve|refuse`; 404 for anyone else; `/me.platform_admin`). `workspace.verification` = none|pending|approved|refused; `Workspace.publishes` (opted in *and* approved, a hybrid property usable in queries) gates every public output: archive, tips, SMS, partner radios, seals, trajet links, « Vérifié par ». Until then the desk works privately under a banner (« En attente de validation »). A verified newsroom keeps its name (409 `verified_name_locked`). The demo reset never verifies. The request's personal data only reaches the Checky team. Public verdicts and the shareable card carry « Rédaction vérifiée par Checky ».
- **Madagascar first, world-ready.** Places are structured `{name, country, region, locality, lat, lng}` geocoded by OpenStreetMap Nominatim and cached in `app.place` (`app/core/places.py`; a Malagasy gazetteer of 23 regions and towns is the fallback and the seed); beats are per newsroom (`workspace.settings.beats`, `DEFAULT_BEATS`); fact-checkers are worldwide (Google Fact Check Tools ClaimReview + IFCN domains in `websearch.FACT_CHECKERS`); figures carry a country; the map is Leaflet + OSM tiles. No hard-coded region list anywhere. **Countries** by ISO code with French names come from `phonenumbers` (`app/core/countries.py`, `GET /public/countries`). The newsroom's country (its verification request, Réglages → Lieu et heure) sets the Veille map's default (`GET …/veille/map?country=` a name or « monde », per-country counts in `countries`; the menu « Madagascar ▾ » above the map recentres it), its World Bank figures, how phone numbers are read (`contact.normalise(value, country)`) and its official sources. Official by rule: an explicit list of government suffixes (`confidence.GOVERNMENT_SUFFIXES`, never a pattern) plus a few institutes; each newsroom adds the rest in Réglages → « Sources officielles » (`app/modules/official.py`, `GET|POST|DELETE …/official-sources`), counted for the other newsrooms of its country only once it is verified, platforms (Facebook, blogs, hosting) refused. Public search covers every newsroom and puts the visitor's country first among equal answers (`country` on `/public/verify`, `/public/match`, `/public/verdicts`, read from the browser's language tag). A tip with no newsroom chosen goes to the newsroom of the region where the rumour circulates, else the nearest in the country, else the nearest one (`verify_public.route_newsroom`), and the visitor is told which and why (`routed`).
- **Honest words.** « Introuvable » is never « Faux »; « Aucune trace trouvée (ne prouve rien) »; dates come from code (`app/core/dates.py`), never from the model; every quote shown is found verbatim in its source or dropped.
- **Assembled from the best existing tools, then one step further** (say so in the pitch; the inventory is in the Doc's Functionality tab §10): NewsGuard's transparency checklist → « Fiabilité de la source » (`app/core/credibility.py`, signals never a score); The Factual's source diversity and tone → the confidence components and a tone lexicon that runs without a model (`app/core/tone.py`); BiasBreak's framing → a dashed reading with verbatim quotes (`app/core/editorial.py`); Aletheia's cited explanations → RAG; FauxLens' per-signal image breakdown → `imagecheck.py` + ingest markers; Logically's AI + humans → the journalist signs; Check-It's multi-signal pipeline → the crew; Snopes, PolitiFact, FactCheck.org, AFP Factuel, Africa Check… → relayed as theirs through Google Fact Check Tools, never re-signed. Media Bias/Fact Check's orientation only when a newsroom curates it in its Annuaire, never automatic. What none does: the road (Le trajet), the signed and attested verdict, the registry of originals with an offline seal, the radio and SMS return path, a crew that keeps working without a model.
- **Demo rules:** no real person's name or phone on screen; demo rows flagged « démo » / « exemple fictif »; never the organisers' FANILO logo; the pitch rumour is FAN-0145 « 72 heures de délestage… » and `demo.DEMO_RUMOUR_TEXT` is what gets pasted.
- **Data model** (migration `80f0950e8a14`): `workspace.settings` JSONB (`ai_enabled`, `beats`, `timezone`, `country`) and the tables `place`, `contact`, `contact_request`, `communique`, `seal_key`, `figure`, `signal`, `route`, `radio_clip`, `radio_partner`, `public_question`, `member_pref`, `sms_subscriber`, `sms_message`, `season`, plus `newsroom_request` and `official_source` (3 Nov) and the column `workspace.verification`. New fields go into the JSONB columns first; a migration only for a new table or index. `demo.seed_extras` calls `seed_demo(db, workspace_id, user_id, items)` on every module in `demo.SEED_MODULES` that defines one (idempotent, each in its own transaction, a failure logged never fatal).
- **Desk navigation** (`components/shell/nav.ts`): five tabs and no more: Ma rubrique (home, `/w/[ws]/rubrique`, the angles inside it and inside each dossier), Vérifier (Analyser merged into it), Dossiers (section tabs Dossiers / Sources), Veille (map with its country menu, the feed, « Ce que les gens demandent », « Entendu à la radio » at `?antenne=1`), Annuaire (section tabs Annuaire / Documents / Communiqués / Chiffres; `components/shell/section-tabs.tsx`). Réglages sits in the avatar menu and the bottom-left dock and holds Équipe (`#equipe`) and Vérification (`#verification`); the Checky team gets « Demandes des rédactions » (`/checky`). Old routes redirect (`/membres`, `/transcriptions`, `components/shell/moved.tsx`). One word each in the UI: « rédaction » for the workspace, « dossier » for each followed rumour; never « desk », « affirmation » or « espace » on screen. **A new feature goes inside an existing page; never add a tab.** French strings for the sections live in `lib/i18n/fr/*.ts` partials spread into `t` (`crew`, `dossier`, `registre`, `rubrique`, `publicLayer`, `team`, `verification`) or imported directly (`research`, `resources`, `publication`).

Key architecture decisions (all reflected in the PRD):

- **Auth:** Better Auth runs in Next.js (email + password, `jwt` plugin, 15-min EdDSA JWTs; `expo` plugin for the phone app, `trustedOrigins` `fanilo://` and, outside production, `exp://**`). The browser gets a token from `/api/auth/token` and calls FastAPI with `Authorization: Bearer`. FastAPI verifies against `/api/auth/jwks` (`app/core/security.py`). Issuer and audience = `BETTER_AUTH_URL` and must match `AUTH_ISSUER` / `AUTH_AUDIENCE` on the API.
- **One Postgres, two schemas:** `better_auth` (Better Auth tables, created by its CLI; not `auth`, which hosted platforms such as Supabase reserve) and `app` (ours, Alembic). User ids in `app` are Better Auth ids (text), no cross-schema FK. `better_auth."user"` is declared read-only in `app/core/models.py` for name joins and excluded from Alembic.
- **No Redis.** Background jobs = `app.job` table claimed with `SELECT … FOR UPDATE SKIP LOCKED` by worker loops inside the API process (`app/workers/queue.py`, `JOB_WORKERS`, default 2). Add a job kind with `@handler("kind")`. Interrupted jobs are requeued on startup.
- **Realtime:** Socket.IO on the API (same port). Handshake requires the JWT; client emits `join` with a workspace id (membership checked). Events: `item.created|updated|deleted`, `comment.created`, `job.progress|done|failed`, `demo.reset`.
- **Claim data model:** `app.item` with `type`, `status`, `tags`, and a JSONB `data` merged on PATCH (new fields need no migration). Claim fields currently in `data`: `ref` (FAN-0142), `first_seen_at` (ISO), `origin` (facebook|whatsapp|tiktok|radio|press|other), `verdict` (confirmed), `verdict_suggested` (AI), `source_count`, `assignee_id`, `demo`.
- **Statuses:** `to_check`, `in_progress`, `verified`, `published`. **Verdicts:** `true`, `misleading`, `false`, `unverifiable`. The AI only suggests; a journalist always confirms.
- **AI gateway** (`app/core/ai.py`): `await complete(messages, tools?, **params)` → `Completion` (content, tool_calls, provider, model, tokens, `.message`); `complete(..., stream=True)` → `Stream` of text deltas with `.completion` set at the end. Plain httpx against OpenAI-compatible `/chat/completions`; **Claude** is the exception (`app/core/claude.py`, official `anthropic` SDK 2.x on httpx2, `CLAUDE_API_KEY`, default `claude-opus-5-5`, `CLAUDE_EFFORT` default `low`, last in the default `LLM_PROVIDERS` and skipped while the key is empty): it translates the OpenAI-style conversation both ways, keeps Claude's own blocks (thinking) on the assistant message as `anthropic_content` and replays them to Claude only, sends no `temperature` (refused since 21 Oct), turns JSON mode into a system line, opts into the server-side refusal fallback (`fallbacks: "default"`), and maps 429/5xx/timeouts onto the gateway's cooldowns; a refusal falls back to the next provider; tests mock it with `claude._transport` (an `httpx2.MockTransport`). Providers follow `LLM_PROVIDERS`, a provider with no key is skipped, and default models live in `PROVIDERS` (override with `LLM_MODEL_*`). Quota-aware (measured: Groq free = 1 000 requests/day but only **8 000 tokens/minute**): each `*_API_KEY` may be a comma list (one per teammate, used in turn; the rotation and cooldowns live in `app/core/keys.py` and are shared by chat, embeddings, Groq Whisper, ElevenLabs, Google Fact Check, Tavily, Sightengine and `IMAGE_DETECTOR_TOKEN`, where a 429 or a refused/used-up key moves to the next key at once; an ElevenLabs key out of credits (401/402) is set aside for an hour); a **429 sets that key aside** for `AI_COOLDOWN` (default 30 s, or the Retry-After) and moves on at once, no retry; 5xx/timeouts are retried `AI_ATTEMPTS` times then set aside; a prompt larger than `LLM_MAX_PROMPT_TOKENS_<PROVIDER>` (Groq 6 000, estimated as JSON chars / 3) skips that provider; other errors (bad key, 400) fall back straight away; a stream only falls back before its first chunk. Every attempt goes to `app.ai_call` (no prompt text). **HTTP clients are shared and kept alive** (`app/core/http.py`, `http.shared(name, transport, timeout)`: one per service, event loop, transport and timeout, idle connections kept 60 s; never close it, close streamed responses instead): chat, embeddings, Whisper and ElevenLabs all use it. Measured from here: a small Groq call 3.4 s with a fresh client against 0.7 s kept alive; ElevenLabs 1.2 s cold, 0.4 s warm; a copilot turn went from 4–5 s to 2–3 s. `AI_CACHE=true` caches answers in `app.ai_cache` (survives restarts and Render's ephemeral disk; re-running an analysis returns the same answer). Prompts are kept small: the checker sends each source's best RAG passages (≤ 2 500 chars each, ≤ 14 000 total), `/ask` 4 passages. Tests reset `ai._turn`/`ai._cooldown` per test. `AiUnavailable` → 503 `ai_unavailable`. Tests mock providers with `ai._transport` (httpx.MockTransport) and `ai._sleep`. Tool calls replayed to another provider after a fallback are translated by `ai._replay`: Gemini requires a thought signature on earlier calls (foreign ones get its documented `skip_thought_signature_validator`), the others get `extra_content` removed.
- **Errors** leave the API as `{"error": {"code", "message"}}`. Outsiders get **404** (not 403) on a workspace.

## Design system

One world for the desk and the public site: **Checky, « ink and paper »**, a minimal theme where colour lives only on verdicts. Documented in `apps/web/DESIGN.md` (+ `.impeccable/design.json`), product truth in `apps/web/PRODUCT.md`, the redesign spec in `docs/superpowers/specs/2026-11-02-checky-redesign-design.md` and its plan in `docs/superpowers/plans/`. For any new screen follow DESIGN.md and run `impeccable detect --json app components` (from `apps/web`).

Rules that must not break:
- Paper ground `#f3f2ee` (dark `#0a0a0b`), surface `#fbfaf7` / `#111113`, ink `#0a0a0b`. The tokens keep their shadcn names (`--background`, `--card`, `--primary`, `--muted`…) plus `--raised`, `--active`, `--nav*`, `--tag-inverted*`, `--toast*`, `--shadow-float`, `--verdict-*`. The values live in `app/globals.css` and in `apps/web/lib/tokens.ts`; `npm test` fails when a text/background pair drops under 4.5:1. **The citron is gone:** the one action of a screen is the ink `primary` (`--action` aliases it); the active step is ink plus motion.
- **No colour outside verdicts.** Verdicts are never colour alone: always icon + word (`VerdictChip`, `VerdictBadge`, the verdict block). Each verdict has fill / on / soft / ink tokens (`on` is `#ffffff` in light, `#0a0a0b` in dark). **AI suggestion = dashed outline**, confirmed = solid. The AI only suggests; a journalist confirms.
- **Every filled background is used with its own foreground token:** `primary`/`primary-foreground`, `nav`/`nav-foreground`, `nav-active`/`nav-active-foreground` (the fixed ink `#0a0a0b` in both themes; theme text on the paper pill is 1:1 in dark), `verdict-*-soft`/`verdict-*-ink`, `verdict-*`/`verdict-*-on`, `tag-inverted`/`tag-inverted-foreground`, `toast`/`toast-foreground`. A class that sets one without the other (`hover:bg-primary` without `hover:text-primary-foreground`) is a bug. Each interactive component lists rest, hover, focus-visible, pressed, selected and disabled with both colours; icons inherit `currentColor`; focus is a 2 px ring in the text colour.
- **Status is not truth:** status uses ink icons from `apps/web/lib/icons.ts` (Phosphor duotone wrapped as `Icon*`; add a missing icon as one export there), never verdict colours. **Contrast:** all text at least 4.5:1 in light and dark against its real background; no opacity on text; placeholders use `--muted-foreground`.
- Type: Bricolage Grotesque (`--font-bricolage`; `font-sans`, `font-display`, `.page-title`) for everything, Cormorant Garamond italic 500 (`--font-cormorant`, `.quote`) only for verbatim quotations. No third face.
- Shape: `--radius` 1.25rem (cards 20, controls and chips fully round, menus 18, tags 6); shadows only on what floats (`--shadow-float`); easings `--ease-out` and `--ease-theme`.
- No eyebrow or kicker above a heading; no coloured border-left accents.
- Signature: **the numbered line** (`components/flow/step-line.tsx`): 1 L'affirmation, 2 Les éléments, 3 La conclusion, each disc waiting / active / done / suggested (dashed) / failed, `full` or `mini`, `claimSteps()` for a dossier. `.signal-mark` underlines a flagged phrase (2 px, 3 px offset).
- The pitch kit (`docs/pitch/`, `scripts/pitch_video.py`) still draws an older « dossier » world (Anton, Special Elite, halftoned photographs in `public/site/`); the app no longer uses them.
- Slices still to land (see the spec, section 5): the new shell, then the phone app and the extension.

### Gotchas
- If the dev server reloads the page in a loop after a crash, stop it and `rm -rf apps/web/.next` (regenerable cache).
- On this machine the running dev server does not pick up edits to `globals.css` (TSX edits are fine), and a plain restart keeps the old CSS (Turbopack's cache): after a CSS change, stop the server, `rm -rf apps/web/.next`, start it again, and check the served stylesheet contains the new rule.
- A session cookie whose session no longer exists used to bounce `/` ↔ `/connexion` forever (proxy.ts trusts the cookie, the layout does not). `getCurrentUser` now redirects to `/api/session/clear`, which deletes the Better Auth cookies and then goes to `/connexion`. Keep that route outside the proxy matcher.
- After a client-side navigation Next keeps the previous route mounted but hidden: never key page-level CSS on something a page renders (the app shell paints its own `bg-background`).
- With `cacheComponents`, a client component that reads the route (`usePathname`, `useParams`) inside a layout breaks dynamic routes (`/verifies/[id]`) unless it sits in `<Suspense>`: the public header and the assistant do.
- Don't use `pkill -f next` from a shell whose command line or cwd contains "next"/the web folder: it kills the shell. Kill by port (`ss -ltnp | grep :3000`).
- The API runs without `--reload` in background tests: restart it after API code changes.
- Render deploys `dev` only when a commit's checks pass (`autoDeployTrigger: checksPass`). After a run of red commits, the first green one was not picked up (2 Nov, `c89bf2c`): check the service's Events after a fix, and if nothing started, push another commit or use Manual Deploy → Deploy latest commit.
- `npm` blocks some install scripts (unrs-resolver); harmless.
